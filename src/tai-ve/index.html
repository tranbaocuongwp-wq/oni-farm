Chơi thẳng trên web

Mở /farm/ là chơi được, không cần tài khoản. Lần đầu vào xong thì service worker đã lưu toàn bộ game lại — sau đó rút mạng vẫn chơi bình thường. Tiến trình nằm trong IndexedDB của trình duyệt, không gửi đi đâu cả.

Cài về màn hình chính (PWA)

iPhone / iPad

Safari → nút Chia sẻ → Thêm vào MH chính. Game mở toàn màn hình, không thanh địa chỉ.

Android

Trong game: ☰ → Cài về màn hình chính. Hoặc Chrome → menu ⋮ → Cài đặt ứng dụng.

Máy tính

Chrome/Edge → biểu tượng cài đặt ở thanh địa chỉ → Cài đặt OniFarm.

Mang save đi máy khác

Trong game bấm ☰ / Esc → Xuất file save, rồi Nhập file save ở máy kia. Cài đặt (tay thuận, cỡ chữ…) thuộc về máy nên không đi theo.

Tự chạy từ mã nguồn

git clone <repo> oni-farm
cd oni-farm
npm install
npm run dev      # http://localhost:1420
npm run build    # xuất static site vào dist/

dist/ là static site thuần — thả lên Cloudflare Pages, Netlify, GitHub Pages hay bất kỳ web server tĩnh nào cũng chạy.
